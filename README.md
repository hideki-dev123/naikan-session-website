# Inner Insight

平田光さんの「内観セッション」を紹介し、申し込みフォームへ案内するための独立したウェブサイトです。隣接する `kidoairaku-marche` とは別プロジェクトとして管理しています。

## ローカルで確認する

```bash
pnpm install
pnpm dev
```

開発サーバーは通常 `http://localhost:3000` で起動します。

## 品質確認

```bash
pnpm test
pnpm lint
pnpm build
```
