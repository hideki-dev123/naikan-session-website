# Airy imagery and seamless sections

The user requested softer section transitions, a more translucent and refined appearance, and newly generated imagery matching the existing world. The supplied copy, Google Form destination, and original I image remain unchanged. Each section uses translucent accents over one continuous washi surface, with no full-width background color change at the transition. The footer fades gently from that surface into the existing dark palette. The mobile application shortcut remains fixed to the viewport, and its prior hide-when-form-visible behavior is unchanged.
